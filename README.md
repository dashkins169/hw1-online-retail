# ДЗ №1. Анализ временного ряда продаж

В работе использован датасет [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail). Я выбрала товар **REGENCY CAKESTAND 3 TIER** (`StockCode = 22423`) и исследовала, как менялось количество его продаж со временем. В анализе учитываются проданные единицы товара (`Quantity`) без отменённых заказов и возвратов.

## Что сделано

Сначала я очистила данные и построила временные ряды продаж по дням, неделям и месяцам. Затем проверила пропущенные даты и возможные выбросы, рассчитала описательные статистики и посмотрела, как меняются среднее и разброс продаж. Для анализа тренда и сезонности использовала STL-декомпозицию, а для проверки стационарности — тесты ADF и KPSS. Основные операции вынесены в функции.

## Результаты

В исходном датасете **541 909 строк**. По выбранному товару после очистки осталось **2 017 записей**, всего продано **13 879 единиц**.

В данных есть **69 дат без наблюдений**, из них **53 субботы**. Я не заменяла такие даты нулями, поскольку отсутствие записей не обязательно означает отсутствие продаж. Методом MAD найдено **15 потенциальных выбросов**. Их оставила без изменений: большие объёмы могут быть связаны с реальными оптовыми заказами.

Среднее число проданных единиц за наблюдаемый день снизилось с **54,89** в первой половине периода до **37,00** во второй. STL-декомпозиция не показала выраженной недельной сезонности (оценка силы сезонности — **0,314**). При декомпозиции пропущенные дни временно интерполировались, поэтому результат нужно интерпретировать с осторожностью.

Для проверки стационарности использовала участок из **48 последовательных недель**. Получилось:

- ADF: $p \approx 3{,}67 \cdot 10^{-9}$;
- KPSS: $p \geq 0{,}1$.

При уровне значимости $\alpha = 0{,}05$ результаты тестов согласуются со стационарностью этого недельного участка. Поэтому дополнительное дифференцирование не потребовалось. На весь исходный дневной ряд этот вывод не распространяется.

## Как запустить

1. Открыть файл [`hw1-online-retail.ipynb`](hw1-online-retail.ipynb) в Kaggle.
2. В **Add Input** подключить датасет **online retail data** с файлом `Online Retail.xlsx` (источник — UCI Online Retail).
3. Выполнить все ячейки по порядку (**Run All**).

Сам датасет в репозиторий не добавлен.
